# 내 장소 지도 (공유)

초대한 사람끼리 같이 쓰는 지도입니다. 지도를 확대해 위치를 터치하면 가게 이름과 사진을 저장하고, 점을 터치하면 저장한 내용을 봅니다.

- **빨간 점 = 가볼 곳, 파란 점 = 가본 곳.** 다른 사람이 저장한 곳은 점 둘레에 검은 테두리
- 장소마다 **링크(인스타 게시물, 블로그, 지도 등)를 최대 10개** 저장하고, 누르면 바로 이동
- 가볼 곳을 다녀오면 상세 화면의 **"다녀왔어요"** 버튼으로 파란 점으로 바꿈 (방문 날짜 기록)
- 저장한 장소 목록에서 전체 / 가볼 곳 / 가본 곳으로 거르기
- 서로 저장한 장소와 사진이 바로 보임 (캘린더와 같은 방식)
- **수정·삭제는 만든 사람만** (서버 규칙으로 막아 둠)
- 검색(저장한 장소 + 주소), 내 위치, 목록, "지도 앱에서 열기"
- 홈 화면에 추가하면 앱처럼 실행 (iPhone)

## 설치 순서 (캘린더 앱과 같은 Supabase 프로젝트를 써도 됩니다)

### 1. Supabase 준비
- 이미 캘린더용 프로젝트가 있으면 그것을 그대로 씁니다. 로그인 계정도 같습니다.
- 없으면 https://supabase.com 에서 가입하고 **New project**(Free, Seoul)를 만듭니다.
- **Project Settings › API** 에서 `Project URL` 과 `anon public` 키를 메모합니다. (service_role 키는 쓰지 마세요)

### 2. DB와 사진 저장소 만들기
**SQL Editor › New query** 에 `supabase/schema.sql` 전체를 붙여넣고 **Run**. 여러 번 실행해도 안전합니다.
장소 표, 사진 저장소(`place-photos`, 비공개), 권한 규칙이 한 번에 만들어집니다.

### 3. 계정 만들기 (프라이빗)
캘린더에서 이미 했다면 건너뜁니다.
- **Authentication › Sign In / Providers** 에서 **Allow new users to sign up** 을 끕니다.
- **Authentication › Users › Add user › Create new user** 로 나와 친구의 이메일·비밀번호를 만들고 **Auto Confirm User** 를 켭니다.

### 4. 올리기 (GitHub Pages)
1. `config.js` 에 `Project URL` 과 `anon` 키를 채웁니다. (공개돼도 안전한 값입니다)
2. GitHub **Public** 저장소를 만들고 이 폴더의 파일을 전부 올립니다. (`icons`, `supabase` 폴더 포함)
3. **Settings › Pages › Branch: main / (root)** 로 켭니다. 생긴 주소를 친구에게도 알려 줍니다.

### 5. iPhone에서 설치
1. **Safari**로 주소를 엽니다.
2. 공유 버튼 › **홈 화면에 추가**
3. **홈 화면 아이콘으로** 열어서 로그인합니다. 처음 **내 위치** 버튼을 누르면 위치 권한을 허용하세요.

## 지도는 카카오맵을 씁니다
- [카카오 개발자](https://developers.kakao.com)에서 앱을 만들고 **JavaScript 키**를 받아 `config.js`의 `KAKAO_JS_KEY`에 넣습니다.
- **[앱] › [플랫폼 키] › [JavaScript 키] › [JavaScript SDK 도메인]** 에 앱 주소(`https://아이디.github.io`, 끝에 `/` 없이)를 등록합니다.
- **카카오맵 사용 설정을 ON**으로 켭니다. 꺼져 있거나 도메인이 다르면 지도가 안 뜹니다(401 오류).
- 검색창은 카카오의 장소(가게 이름)·주소 검색을 씁니다. 검색 결과는 지도를 옮기는 데만 쓰고 **저장하지 않습니다.** 저장되는 것은 내가 터치한 위치와 직접 입력한 이름뿐입니다. (카카오 약관상 검색 결과 저장은 허용되지 않습니다.)
- 일반 지도와 위성 지도를 오른쪽 버튼으로 바꿀 수 있습니다. 어두운 지도 스타일은 없습니다.
- REST API 키와 Admin 키는 이 앱에 쓰지 않습니다. 절대 `config.js`에 넣지 마세요.

## 알아둘 점
- 장소·사진은 Supabase에 저장됩니다. 사진은 로그인한 사람만 볼 수 있는 비공개 저장소에 있고, 앱이 1시간짜리 임시 주소로 불러옵니다.
- 사진은 올리기 전에 긴 변 1280px로 줄입니다. Supabase 무료 저장 공간(1GB)이면 둘이서 쓰기에 충분합니다.
- 지도 이미지와 검색은 카카오맵에서 받아옵니다. 보고 있는 지도 영역과 검색어가 카카오로 전달됩니다. 저장한 이름·사진·메모는 Supabase 계정에만 저장됩니다.
- 카카오맵 무료 이용량(지도 로드 하루 30만 건 등)은 첫 번째 앱에만 적용되고 정책이 바뀔 수 있습니다. 둘이 쓰는 정도는 문제없지만 카카오 개발자 사이트의 쿼터 안내를 가끔 확인하세요.
- Supabase 무료 프로젝트는 7일간 아무도 접속하지 않으면 일시 중지됩니다. 대시보드의 Restore로 복구되며, 캘린더 앱의 10분 호출 설정(GitHub Actions)을 같은 프로젝트에 쓰고 있다면 멈추지 않습니다.
- 프로젝트 관리자(본인)는 대시보드에서 모든 데이터를 볼 수 있습니다.
- 오프라인에서는 지도 이미지와 저장 내용을 불러오지 못합니다.
